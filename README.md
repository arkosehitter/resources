**Important Note:** I have not checked every single file in this repository. While most files are probably fine, there is a possibility that a few may contain backdoors.

## Checking for Backdoors

- Look for any Scripts that have weird names.
- Search the entire file for any of these (CTRL + SHIFT + F):
   - "require"
   - "HttpService"
   - "TeleportService"
   - weird remote event names
   - long encoded strings
   - Discord Webhooks

Always check your files.

## Plugin Usage

If installing a plugin found here, open the plugins folder on your pc from studio, and drag the `.rbxmx` file into that folder, then restart studio.
